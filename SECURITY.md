# Security

Report vulnerabilities privately through [GitHub security advisories](https://github.com/lmctl-ai/lmmcp/security/advisories/new)
(the repository's **Security → Report a vulnerability** page). Include a minimal
reproducer using a loopback mock, the affected version or commit, and the impact.
Do not put credentials, private MCP configurations or exploit details in public issues.

If private vulnerability reporting is unavailable, open an issue asking the
maintainers to enable it without including sensitive details. General bugs can
use public issues with sanitized mock inputs.
